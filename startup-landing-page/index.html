    Frequently asked questions.

    Everything you need to know about Forma.

    What is Forma?

    Forma is a productivity platform designed to help you organize tasks, manage time and build better habits.

    Is Forma free?

    Yes! The Basic version is free and includes essential productivity tools.

    Can I use Forma on my phone?

    Yes! Forma is designed to work on mobile phones, tablets and computers.

    Can I track my daily habits?

    Yes! You can use the habit tracker to check off your daily activities.

    Does Forma save my notes?

    This HTML and CSS demonstration does not automatically save notes. A future version with JavaScript or a backend could support this.
